1. EXECUTIVE SUMMARY
--------------------
A deep diagnostic inspection was executed on all stream sources returned by CinePro 
for "Spider-Man: Brand New Day" (TMDB ID: 969681). 

Key Findings:
1. Spider-Man: Brand New Day is an unreleased movie (scheduled theatrical release in 2026).
   The actual studio film is not yet released anywhere in the world.
2. Despite this, CinePro scrapers return 17 distinct stream sources, and several 
   servers report full-length movie durations between 137.0 minutes and 145.0 minutes 
   (8,221 to 8,700 seconds).
3. None of these "full length" streams can be cleanly played in standard browser 
   players due to 5 distinct technical failure mechanisms:
   - Artificial PNG header obfuscation (prepended 120-byte PNG header before MPEG-TS).
   - Scraper proxy corruption (CinePro /v1/proxy rewrites binary .html chunks as text).
   - Upstream CDN timeouts / connection drops (e.g., mov3.4pa.top).
   - Expired or invalid CDN links (cdn.boomchick.org returning 404).
   - Invalid token hashes (LMScript returning "WRONG HASH!").
   - Disguised file extensions (.txt playlists and .woff2 video chunks).

- Target Hosts: cdn.boomchick.org, cdn2.boomchick.org
- HTTP Status: 404 Not Found
- Response Payload: "Link expired" or "Invalid link"
- Why It Fails:
  The tokens generated by BoomChick scrapers have extremely short TTLs (time-to-live)
  or require active browser session cookies. By the time the player requests the stream,
  the upstream CDN rejects the request with HTTP 404.


STREAM #9: Icefy (TIK 1)
- Provider: Icefy
- Manifest URL: https://tik.1x2.space/playlist/.../master.m3u8
- HTTP Status: 200 OK
- Reported Manifest Duration: 8,700.7 seconds (145.01 minutes / 2.42 hours)
- Segment Count: 2,176 segments from tik2.1x2.space
- Segment Status: 200 OK
- Segment Content-Type: image/png (48,624 bytes)
- Why It Cannot Be Played:
  * Binary inspection reveals the first 120 bytes are an artificial PNG image header:
    Hex: 89 50 4e 47 0d 0a 1a 0a 00 00 00 0d 49 48 44 52 ... (IHDR 1x1 PNG).
  * The actual MPEG-TS sync byte (0x47) only begins at byte offset 120.
  * Standard browser HLS players (HLS.js / Safari native) require MPEG-TS packets to 
    start with the standard 0x47 sync byte at offset 0.
  * Encountering the PNG signature causes HLS.js demuxer workers to throw 
    "TS packet did not start with 0x47" / fragParsingError, causing playback to freeze
    and stall permanently.

4. CONCLUSION & ROOT CAUSES OF "FULL LENGTH BUT UNPLAYABLE"
-----------------------------------------------------------
1. Scraper Fake / Placeholders: 
   Because "Spider-Man: Brand New Day" is a 2026 film that has not been released,
   scrapers crawl fan-compilations or placeholder loops that declare 145 minutes 
   of playback in the M3U8 tags.
2. Anti-Scraping Steganography:
   Hosts (such as 1x2.space) deliberately prepend fake 120-byte PNG headers to 
   MPEG-TS chunks to disguise video traffic as image requests. Browser demuxers 
   reject these files because the MPEG-TS sync byte 0x47 is not at byte offset 0.
3. Proxy Mangling:
   CinePro's proxy engine is hardcoded to treat ".html" and ".txt" files as string 
   manifests, which mutates binary MPEG-TS chunks and corrupts the video container.
4. CDN Expiration & Timeouts:
   Upstream hosts frequently invalidate tokens or block scraper IPs via Cloudflare 
   or network timeouts.
